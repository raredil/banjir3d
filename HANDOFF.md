## What works
- Validation pipeline: `observed.yml` (ERA5, CHIRPS, IMERG via CMR, PetaBencana counts, reported-impact excerpts) -> `validate.yml` (edit `verification/observed/request.json`: event, drains, rain `era5`|`era5_land`|`chirps`|`imerg`, k; one push = one run, several pushes run in parallel) -> release `validation-jakarta-<event>-v<n>` with hmax/mask/summary per D and `<event>_scores.json` (reports hit, depth error, `dki_flooded_km2`, `reported`). Scores copied to `verification/observed/scores-<event>-imerg.json`.
- Observed-flood mode (3 events, IMERG per zone) and exposure (buildings, people, per kecamatan, CSV) in the Simulasi panel; previews `previews/phase4/event-exposure/`.
- Drain sink 0 mm/h (`data/engine/calibration.json`) is from an OLD test (old scoring, old pack); not re-run. Current skill: see skill.json (v8).
- Engine pack (30 m UTM 48S, 1718 × 1737): carved OSM channels, n and CN from IO land cover 2024 + SoilGrids, sea mask, GLO-90 stream network (107k cells ≥ 1 km²).
- Engine v2: local inertial, CN runoff, upstream inflows (NRCS lag + UH, no double counting), sea level, transmissive edges; WebGPU in a worker with CPU fallback (region forced to 90 m without WebGPU).
- Whole-region run, 1 Jan 2020 storm, 90 m CPU (Node): 13.5 min, mass error 5e-15; water follows valleys/rivers. 4.4 km box at 30 m in the browser: 39 s CPU, flood along Ciliwung (Kampung Melayu–Bukit Duri).
- Exports: depth GeoTIFF (EPSG:32748, float32, nodata -9999), coloured GeoTIFF, HTML map (Leaflet + OSM from CDN), PNG figure (title, legend, scale, north, sources), JSON provenance.
- Region-wide 30 m in tiles: set `tiles` in `verification/observed/request.json` (`{"box": [W,S,E,N], "n": [5,4], "buffer_km": 2}`, k 1) -> validate.yml runs one job per tile and `mosaic_tiles.py stitch` joins them by core (seam check in the summary).
- Return-period design rain: `design-rain.yml` (push of `pipeline/design_rain*.py`) -> release `design-rain-jakarta-<date>-r<n>`; copy its `design_rain_jakarta.json` to `data/rain/`; the app option "Kala ulang" appears only when that file exists.
- Tests: `cd web && npm run check` (104), `python -m pytest -q verification/observed/test_compare.py` (2, needs pyproj), `cd pipeline && python -m pytest -q` (23). `python3 tools/check.py` (2 warnings: IDEAS.md, MUST IDs format).
