# Gate 0 preview (sample data, 2026-10-23)
Software-rendered in the cloud session (no GPU), not final quality. Data = 10 × 10 km Ciliwung sample built locally. Layers whose hosts are blocked in the cloud session (FABDEM, OSM, WorldPop, geoBoundaries) appear as failed here; they are built by the Region pack Action.
- `contact.jpg`: map views (satellite, land cover, satellite + buildings, elevation + water occurrence)
- `map-imagery.jpg`: Sentinel-2 composite + Overture buildings at street level
- `map-relief.jpg`: lowland elevation ramp + JRC water occurrence
- `catalog.jpg`: data catalog page
- `region-jakarta.jpg` (2026-10-24): new main region (ADR 0005). Orange = simulation domain (mainland DKI Jakarta + 10 km buffer), brown = DKI boundary (Kepulauan Seribu excluded), blue = 10 × 10 km sample, grey = the 6 DEMNAS sheets used. Background: Copernicus GLO-30 hillshade, 40 m.
